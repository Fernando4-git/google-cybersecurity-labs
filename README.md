## Documentation Standards

Each lab will be documented using a structured approach:

1. Objective – What I wanted to learn or investigate.
2. Environment – Systems and tools used.
3. Scenario – Description of the activity.
4. Methodology – Steps and commands performed.
5. Evidence – Screenshots, outputs, and results.
6. Analysis – Technical observations and findings.
7. Key Takeaways – What I learned from the exercise.
